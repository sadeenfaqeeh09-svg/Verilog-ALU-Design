# 🧠 Verilog ALU Design

## Description
This project implements an Arithmetic Logic Unit (ALU) using Verilog HDL.

The ALU is designed using multiple modeling styles:
- Behavioral modeling
- Dataflow modeling
- Structural modular design

The project demonstrates how different Verilog design approaches can be used to implement arithmetic and logical operations.

---

## 🎯 Objectives
- Design an ALU using Verilog HDL
- Implement arithmetic and logic operations
- Compare behavioral and dataflow modeling
- Build the ALU using modular components

---

## ⚙️ Operations Supported
- Addition
- Subtraction
- Bitwise AND
- Bitwise OR

---

## 🧩 Modules

- **add.v**
  - Implements addition operation

- **sub.v**
  - Implements subtraction operation

- **bitwiseAnd.v**
  - Performs AND operation

- **bitwiseOr.v**
  - Performs OR operation

- **fullAdderOB.v**
  - Full adder building block

- **behavioralALU.v**
  - ALU implemented using behavioral modeling

- **dataflowALU.v**
  - ALU implemented using dataflow modeling

---

## 🚀 Features
- Multiple Verilog design styles
- Modular implementation
- Clear separation of operations
- Reusable components (Full Adder)
- Demonstrates HDL design concepts

---

## ▶️ How to Run

Use a Verilog simulator such as:
- ModelSim
- Vivado Simulator

### Example:
- vlog *.v
